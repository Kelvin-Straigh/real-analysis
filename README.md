# real-analysis

Worked proofs and notes from my self-study of real analysis, following MIT OpenCourseWare 18.100A (Real Analysis, Fall 2020) and Jiří Lebl's *Basic Analysis I*.

I am building the mathematical foundations for doctoral study in mathematical finance and machine learning. Each proof is written in my own words and reviewed for correctness before it is added here.

## Contents

| Lecture | Topic | Proofs |
|---|---|---|
| 1 | Sets, set operations and mathematical induction | Sum of the first n odd numbers; geometric series; Bernoulli's inequality |

More lectures will be added as I progress.

## Format

Proofs are written in LaTeX. Each folder contains the `.tex` source and a compiled `.pdf`.
